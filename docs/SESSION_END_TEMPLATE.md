# АН Эва — Инструкция завершения сессии

## Когда использовать
В конце каждого чата пользователь пишет:
```
ЗАВЕРШАЕМ СЕССИЮ
Инструкция: https://raw.githubusercontent.com/semiekhin/an-eva/main/docs/SESSION_END_TEMPLATE.md
```

## Что делает ассистент

### Шаг 1: Подтянуть текущие документы из GitHub
Fetch и прочитать:
- https://raw.githubusercontent.com/semiekhin/an-eva/main/docs/AN_EVA_CURRENT.md
- https://raw.githubusercontent.com/semiekhin/an-eva/main/docs/AN_EVA_KNOWLEDGE.md
- https://raw.githubusercontent.com/semiekhin/an-eva/main/docs/CHANGELOG.md
- https://raw.githubusercontent.com/semiekhin/an-eva/main/docs/AN_EVA_PROJECT.md

### Шаг 2: Сравнить с тем что сделано в чате
- Что реально было сделано в этой сессии?
- Какие файлы менялись?
- Какие баги нашли и решили?
- Что осталось незавершённым?

### Шаг 3: Выдать bash-блок для обновления документов
Один блок `cd ~/Projects/an-eva && cat > docs/...` для каждого файла который нужно обновить:

**AN_EVA_CURRENT.md** — ПЕРЕЗАПИСАТЬ полностью:
- Дата и время последней сессии
- Текущая фаза
- Что сделано в этой сессии (конкретный список)
- Что работает
- Что не работает / проблемы
- Следующий шаг (одна конкретная задача)
- Последние изменённые файлы
- Важный контекст для следующего чата
- Невыполненные команды (если есть)

**AN_EVA_KNOWLEDGE.md** — ДОПОЛНИТЬ (не перезаписывать):
- Новые баги/решения/уроки из этой сессии
- Формат: ## дата: краткое описание → Проблема / Решение / Почему

**CHANGELOG.md** — ДОПОЛНИТЬ (не перезаписывать):
- Строка с датой и списком что сделано

**AN_EVA_PROJECT.md** — обновить ТОЛЬКО если менялась архитектура или план. Если нет — не трогать.

### Шаг 4: Выдать команду коммита
```bash
cd ~/Projects/an-eva
git add -A && git commit -m "session: ДД.ММ.ГГГГ — краткое описание" && git push
```

### Шаг 5: Выдать блок для нового чата
```
Продолжаем проект АН Эва. Подтяни текущий статус:
https://raw.githubusercontent.com/semiekhin/an-eva/main/docs/AN_EVA_CURRENT.md
```

## Документы проекта

| Документ | Назначение | Обновление |
|----------|------------|------------|
| AN_EVA_PROJECT.md | Полное ТЗ, архитектура, план | Редко (при изменении плана) |
| AN_EVA_CURRENT.md | Текущий статус, что дальше | Каждую сессию (перезапись) |
| AN_EVA_KNOWLEDGE.md | Баги, решения, уроки | Каждую сессию (дополнение) |
| CHANGELOG.md | Лог изменений | Каждую сессию (дополнение) |
| SESSION_END_TEMPLATE.md | Эта инструкция | Редко |

## Принципы
- Источник правды — GitHub
- Документация обновляется через git (cat > файл, git commit, git push)
- Не скачивать файлы из Claude — всё через терминал
- KNOWLEDGE и CHANGELOG — только дополнять, не перезаписывать
- PROJECT.md также хранится в Project Knowledge Claude.ai (обновляется редко)
