# АН Эва — Система управления сессиями

## Документы проекта

| Документ | Где хранится | Назначение | Кто обновляет |
|----------|-------------|------------|---------------|
| `AN_EVA_PROJECT.md` | `docs/` в репо + Project Knowledge Claude.ai | Полное ТЗ, архитектура, план | Оркестратор (Claude.ai) при изменении плана |
| `AN_EVA_CURRENT.md` | `docs/` в репо + Project Knowledge Claude.ai | Текущий статус, что сделано, что дальше | Оркестратор в конце каждого чата |
| `AN_EVA_KNOWLEDGE.md` | `docs/` в репо | Баги, решения, уроки (накопительный) | Оркестратор в конце каждого чата |
| `CHANGELOG.md` | `docs/` в репо | Лог изменений по датам | Оркестратор в конце каждого чата |

**Project Knowledge в Claude.ai** — всегда содержит актуальные `AN_EVA_PROJECT.md` и `AN_EVA_CURRENT.md`. Это гарантирует что новый чат сразу видит полный контекст без необходимости подтягивать файлы.

---

## Завершение чата (ОБЯЗАТЕЛЬНО перед закрытием)

### Шаг 1: Оркестратор создаёт/обновляет документы

**AN_EVA_CURRENT.md** — полностью перезаписывается каждый раз:
```markdown
# Текущий статус АН Эва

📅 **Последняя сессия:** [дата], [время] MSK
**Фаза:** [номер и название текущей фазы]

## ✅ Что сделано в этой сессии
- [конкретный список выполненных задач]

## 🔄 Текущее состояние
### Работает:
- [что работает]

### Не работает / Проблемы:
- [что сломано или не доделано]

## 🔜 Следующий шаг
[Одна конкретная задача которую нужно сделать первой в следующем чате]

## 📁 Последние изменённые файлы
- [файл] — [что изменилось]

## ⚠️ Важный контекст для следующего чата
[Всё что нельзя забыть: незакоммиченные изменения, ожидающие решения, промежуточные результаты]
```

**AN_EVA_KNOWLEDGE.md** — дополняется (не перезаписывается):
```markdown
## [дата]: [Краткое описание]
**Проблема:** [что случилось]
**Решение:** [как починили]
**Почему:** [корневая причина]
```

**CHANGELOG.md** — дополняется:
```markdown
## [дата]
- [что сделано, кратко]
```

### Шаг 2: Push в репо

На MacBook (или попросить Sergio):
```bash
cd ~/Projects/an-eva
git add -A && git commit -m "session: [дата] — [краткое описание]" && git push
```

### Шаг 3: Обновить Project Knowledge в Claude.ai

1. Скачать обновлённые `AN_EVA_PROJECT.md` и `AN_EVA_CURRENT.md`
2. Зайти в Project → Project Knowledge → заменить файлы

## Начало нового чата

### Что писать в первом сообщении:

```
Продолжаем проект АН Эва.
Репо: github.com/semiekhin/an-eva
Сервер: 72.56.64.91:2222, путь: /opt/an-eva/
Документация в Project Knowledge актуальна.
Подтяни текущий статус: 
https://raw.githubusercontent.com/semiekhin/an-eva/main/docs/AN_EVA_CURRENT.md
```

### Что делает оркестратор (Claude.ai):

1. Читает `AN_EVA_PROJECT.md` из Project Knowledge (видит автоматически)
2. Читает `AN_EVA_CURRENT.md` из Project Knowledge (видит автоматически)
3. Fetch'ит свежий `AN_EVA_CURRENT.md` из GitHub (на случай если Knowledge не обновлён)
4. Понимает где мы остановились
5. Предлагает следующий шаг

## Передача задачи в 1Code

Когда оркестратор формирует ТЗ для 1Code, формат:

```
ПРОЕКТ: АН Эва
ФАЗА: [номер]
ЗАДАЧА: [конкретное описание]

КОНТЕКСТ:
- Прочитай docs/AN_EVA_PROJECT.md — полное ТЗ
- Прочитай refs/sofia/[файл].py — референс из Софии

ЧТО СДЕЛАТЬ:
1. [конкретный шаг]
2. [конкретный шаг]

ПРАВИЛА:
- Код пишем в ~/Projects/an-eva/
- Файлы в /opt/sofia-gpt/, /opt/bot/, /opt/bot-dev/, /opt/rizalta-webchat/ НЕ ТРОГАТЬ
- После каждого файла — тест
- git commit после каждой значимой группы

ТЕСТ УСПЕХА:
[как проверить что задача выполнена]
```
